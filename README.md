# 漢字テスト | Kanji Test

Website latihan kanji bahasa Jepang yang dibuat untuk membantu mahasiswa Pendidikan Bahasa Jepang semester 5 Universitas Brawijaya belajar, berlatih, dan menguji kemampuan kanji melalui berbagai jenis quiz interaktif.

## 🌸 About

このウェブサイトは、Brawijaya大学の日本語教育学科5学期生のために作りました。

Website ini dibuat sebagai media belajar mandiri untuk mahasiswa Pendidikan Bahasa Jepang semester 5 Universitas Brawijaya, sekaligus sebagai media latihan bersama teman-teman.

## ✨ Features

- 🗺️ Kanji Map
- 📝 Kanji Quiz
- 🔄 Reverse Recall
- 熟語 Jukugo Evaluation
- 🧠 Context & HOTS Questions
- 🔊 Answer Sounds
- 📊 Score & Result
- 📚 Materi Kanji Pertemuan 1–6

## 🎯 What You Can Practice

- Kunyomi & Onyomi
- Bushu
- Kanji Recall
- Jukugo & Reading
- Arti kosakata
- Pemahaman kanji dalam konteks
